The Projects group contains this guide alongside the Reference Lab's project endpoints.
Start by reading a project, then inspect the update operation to see how request
parameters and bodies differ.

## Read a project

The read operation inherits parameters from its path. Its response uses a reusable
project schema, so you can follow the schema reference to inspect individual fields.

## Update a project

The update operation overrides an inherited parameter and requires a request body.
Compare its request example with the read response to see which fields can be sent
and which are returned by the server.
